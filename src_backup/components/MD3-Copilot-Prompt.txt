# CONTEXTO: DocenteDoc AI – Material Design 3 (MD3) Pure System
# OBIETTIVO: Creare o modificare componenti React/TSX totalmente MD3-compliant
# REGOLE DA SEGUIRE SCRUPOLOSAMENTE:

1️⃣ **Componenti**
- Usare esclusivamente componenti base M3 (M3Button, M3Card, M3Typography, M3Dialog, M3ListItem, M3TextField, ecc.)
- Evitare elementi raw (<div>, <span>, <input>) se esiste un M3 component equivalente
- Tutti i props originali dei componenti legacy devono essere preservati per compatibilità

2️⃣ **Typography**
- Testo sempre con M3Typography
- Varianti da usare coerenti con la gerarchia MD3 (label-small, label-large, body-small, body-medium, body-large, headline-small, ecc.)
- Non usare classi Tailwind per font-size, line-height o tracking
- Mantenere uppercase, letterSpacing e opacity solo se coerenti con token MD3

3️⃣ **Colori**
- Tutti i colori devono derivare dai token MD3:
  - var(--md-sys-color-primary)
  - var(--md-sys-color-on-surface)
  - var(--md-sys-color-error)
  - var(--md-sys-color-surface-container-*)
- Non usare valori hardcoded tipo "#fff", "#000" o RGB manuali
- Override colori solo tramite ThemeProvider MD3 o props compatibili

4️⃣ **Spacing & Layout**
- Gap, margin, padding, dimensioni devono usare token MD3:
  - spacing['1'] ... spacing['14']
- Grid e flex layout permessi solo per posizionamento e layout
- Tailwind può essere usato solo per layout responsivo, mai per colori, tipografia, elevation, shape

5️⃣ **Shape & Elevation**
- Angoli e bordi: corner-small/medium/large/extralarge
- Elevation: var(--md-sys-elevation-level1/2/3/4/5)
- Non usare valori hardcoded per border-radius o box-shadow

6️⃣ **Motion & Interactions**
- Animazioni, transizioni e hover/focus devono usare easing, duration e motion token MD3
- Micro-interazioni coerenti con Material Design 3

7️⃣ **Accessibility**
- Tutti i componenti devono rispettare WCAG AA
- Focus visibile e coerente
- ARIA labels e ruoli corretti
- Keyboard navigation completa
- Touch targets ≥ 44px

8️⃣ **CSS & Hardcoded**
- Non usare classi CSS legacy
- Non usare Tailwind per colori, tipografia, spacing, shadow o borders
- Tutto deve derivare da token MD3 o M3 component props
- Inline styles consentiti solo se derivati dai token MD3

9️⃣ **API & Props**
- Tutte le props dei componenti legacy devono essere mantenute
- Non rompere l’API esistente
- Event handlers preservati (onClick, onChange, onFocus, onBlur, ecc.)

🔟 **Testing & Validazione**
- TypeScript deve compilare senza errori
- Build Vite completare con successo
- Verifica responsive e light/dark mode
- Controllare funzionalità core prima di commit

# ISTRUZIONE PER COPILOT:
"Genera un componente React/TSX conforme al sistema MD3 puro. Tutti gli stili devono usare token MD3, M3Typography per il testo, M3 componenti per UI elements. Mantieni l’API compatibile con eventuali props legacy. Assicurati accessibilità completa, responsive layout e transizioni motion MD3. Non usare classi CSS legacy o valori hardcoded. Commenta eventuali scelte critiche."
