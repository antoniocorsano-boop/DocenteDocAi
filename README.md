# DocenteDoc AI

Assistente AI per docenti basato su Flowise.

## Requisiti

- Node.js 18+
- npm o yarn

## Installazione

```bash
npm install
```

## Configurazione

Crea un file `.env` con le seguenti variabili:

```env
# API Keys
OPENAI_API_KEY=your_openai_key

# Flowise
FLOWISE_USERNAME=admin
FLOWISE_PASSWORD=your_password
```

## Avvio

```bash
npm start
```
