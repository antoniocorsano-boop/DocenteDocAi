# Icon System

Material Symbols icon library for DocenteDoc AI application.

## Overview

DocenteDoc uses **Material Symbols** - Google's comprehensive icon library with 2,500+ icons in three styles:

- **Outlined**: Default style, clean and minimal
- **Rounded**: Friendly and approachable
- **Sharp**: Modern and precise

## Installation

```bash
# Via CDN (add to index.html)
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
```

## Usage

### Basic Icon

```html
<span class="material-symbols-outlined">
  home
</span>
```

### Styled Icon

```css
.icon {
  font-family: 'Material Symbols Outlined';
  font-size: 24px;
  color: #6750a4;
}
```

## Accessibility Guidelines

### Screen Readers

Always provide accessible labels for icon-only buttons:

```html
<!-- Bad -->
<button>
  <span class="material-symbols-outlined">delete</span>
</button>

<!-- Good -->
<button aria-label="Delete document">
  <span class="material-symbols-outlined" aria-hidden="true">delete</span>
</button>
```

### Touch Targets

Ensure icon buttons meet minimum 44x44px touch target:

```css
.icon-button {
  width: 44px;
  height: 44px;
  padding: 10px;
  border: none;
  background: transparent;
  cursor: pointer;
}

.icon-button .icon {
  font-size: 24px;
}
```

### Color Contrast

Icons must meet WCAG 2.1 AA contrast requirements:

- **UI Icons**: 3:1 minimum contrast ratio
- **Informational Icons**: 4.5:1 minimum contrast ratio

## Implementation

### CSS

```css
.icon {
  font-family: 'Material Symbols Outlined';
  font-size: 24px;
  color: currentColor;
  user-select: none;
  vertical-align: middle;
}

/* Filled variant */
.icon--filled {
  font-variation-settings: 'FILL' 1;
}

/* Weight variants */
.icon--light {
  font-variation-settings: 'wght' 300;
}

.icon--regular {
  font-variation-settings: 'wght' 400;
}

.icon--bold {
  font-variation-settings: 'wght' 700;
}

/* Size variants */
.icon--small { font-size: 16px; }
.icon--medium { font-size: 24px; }
.icon--large { font-size: 32px; }
.icon--xlarge { font-size: 48px; }
```

### React Component

```tsx
interface IconProps {
  name: string;
  size?: 'small' | 'medium' | 'large' | 'xlarge';
  filled?: boolean;
  color?: string;
  className?: string;
}

export const Icon: React.FC<IconProps> = ({ 
  name, 
  size = 'medium',
  filled = false,
  color,
  className = '',
}) => {
  const sizeMap = {
    small: '16px',
    medium: '24px',
    large: '32px',
    xlarge: '48px',
  };

  return (
    <span
      className={`material-symbols-outlined ${className}`}
      style={{
        fontSize: sizeMap[size],
        color: color,
        fontVariationSettings: filled ? '"FILL" 1' : '"FILL" 0',
      }}
      aria-hidden="true"
    >
      {name}
    </span>
  );
};
```
