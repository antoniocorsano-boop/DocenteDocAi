## Accessibility Guidelines

### Contrast Ratios

All color combinations meet WCAG 2.1 AA standards:

- **Normal Text**: Minimum 4.5:1 contrast ratio
- **Large Text**: Minimum 3:1 contrast ratio
- **UI Components**: Minimum 3:1 contrast ratio

### Usage Examples

```css
/* Primary button */
background-color: #6750a4; /* Primary 60 */
color: #ffffff; /* On Primary */

/* Error message */
background-color: #fee; /* Error Light background */
color: #c62828; /* Error Dark text */
border: 1px solid #f44336; /* Error border */

/* Disabled state */
background-color: #f5f5f5; /* Gray 100 */
color: #9e9e9e; /* Disabled text */
cursor: not-allowed;
```

## Dark Mode Support

All colors have dark mode variants for consistent theming:

- Primary colors automatically adjust luminance
- Surfaces become darker (#121212 base)
- Text inverts to light-on-dark
- Semantic colors maintain meaning while adjusting brightness
