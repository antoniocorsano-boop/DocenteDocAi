# Spacing System

Material Design 3 spacing scale for consistent layout and rhythm.

## Base Unit

The spacing system uses an **8px base unit** for all measurements.

```css
--spacing-unit: 8px;
```

## Component Spacing

### Buttons

```css
/* Button padding */
padding: var(--spacing-2) var(--spacing-3); /* 16px 24px */

/* Icon button padding */
padding: var(--spacing-1); /* 8px */

/* Button group gap */
gap: var(--spacing-2); /* 16px */
```

### Cards

```css
/* Card padding */
padding: var(--spacing-3); /* 24px */

/* Card gap (between elements) */
gap: var(--spacing-2); /* 16px */

/* Card margin */
margin-bottom: var(--spacing-3); /* 24px */
```

### Forms

```css
/* Input padding */
padding: var(--spacing-2); /* 16px */

/* Form field gap */
margin-bottom: var(--spacing-3); /* 24px */

/* Label margin */
margin-bottom: var(--spacing-1); /* 8px */

/* Helper text margin */
margin-top: var(--spacing-1); /* 8px */
```

### Layouts

```css
/* Page padding */
padding: var(--spacing-4); /* 32px */

/* Section spacing */
margin-bottom: var(--spacing-6); /* 48px */

/* Grid gap */
gap: var(--spacing-3); /* 24px */
```

## Responsive Spacing

Spacing scales proportionally on smaller screens:

```css
/* Mobile (< 600px) */
--page-padding: var(--spacing-2); /* 16px */
--section-spacing: var(--spacing-4); /* 32px */

/* Tablet (600px - 1024px) */
--page-padding: var(--spacing-3); /* 24px */
--section-spacing: var(--spacing-5); /* 40px */

/* Desktop (> 1024px) */
--page-padding: var(--spacing-4); /* 32px */
--section-spacing: var(--spacing-6); /* 48px */
```

## Accessibility Guidelines

- **Touch Targets**: Minimum 44x44px for interactive elements (use `padding: var(--spacing-2)`)
- **Content Spacing**: Minimum 16px between related content groups
- **Focus Indicators**: 2-4px offset from element edge
