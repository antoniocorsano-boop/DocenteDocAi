# Typography System

Material Design 3 typography scale for DocenteDoc AI application.

## Font Families

### Primary Font: Roboto

Roboto is the primary typeface for body text and UI elements.

```css
font-family: 'Roboto', sans-serif;
```

### Display Font: Roboto Condensed

Roboto Condensed is used for headlines and large display text.

```css
font-family: 'Roboto Condensed', sans-serif;
```

### Monospace Font: Roboto Mono

Roboto Mono is used for code snippets and technical content.

```css
font-family: 'Roboto Mono', monospace;
```

## Type Scale

Material Design 3 type scale with 13 semantic levels:

### Display

Large, expressive type for marketing and hero sections.

<Typeset
  fontFamily="'Roboto Condensed', sans-serif"
  fontSizes={[
    '57px', // Display Large
    '45px', // Display Medium
    '36px', // Display Small
  ]}
  fontWeight={400}
  sampleText="DocenteDoc AI"
/>

**Usage:**
- Display Large (57px/64px): Hero headings, splash screens
- Display Medium (45px/52px): Large marketing headers
- Display Small (36px/44px): Section headers

### Headline

Emphasized, short-form text for section headers.

<Typeset
  fontFamily="'Roboto Condensed', sans-serif"
  fontSizes={[
    '32px', // Headline Large
    '28px', // Headline Medium

**Usage:**
- Headline Large (32px/40px): Page titles
- Headline Medium (28px/36px): Section headings

## Line Height

Line height values ensure readability and vertical rhythm:

- **Display/Headline**: 1.2 (tight, for large text)
- **Title/Label**: 1.4 (medium, for UI elements)
- **Body**: 1.5 (comfortable, for reading)

## Letter Spacing

Tracking adjustments for optimal legibility:

```css
/* Display Large */
letter-spacing: -0.25px;

/* Headline Large */
letter-spacing: 0;

/* Body Medium */
letter-spacing: 0.25px;

/* Label Small */
letter-spacing: 0.5px;
```

## Responsive Typography

Typography scales proportionally across screen sizes:

```css
/* Mobile (< 600px) */
--headline-large: 28px;
--body-large: 14px;

/* Tablet (600px - 1024px) */
--headline-large: 32px;
--body-large: 16px;

/* Desktop (> 1024px) */
--headline-large: 36px;
--body-large: 16px;
```

## Accessibility Guidelines

### Readability

- **Minimum Size**: 12px for body text
- **Optimal Reading Width**: 50-75 characters per line
- **Line Height**: Minimum 1.5 for body text

### Contrast

All text meets WCAG 2.1 AA contrast requirements:

- **Normal Text** (< 18px): 4.5:1 minimum
- **Large Text** (≥ 18px or ≥ 14px bold): 3:1 minimum
