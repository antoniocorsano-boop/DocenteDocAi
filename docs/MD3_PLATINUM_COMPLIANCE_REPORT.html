🛠️ Developer Guidelines

Using Semantic Tokens

✅ Correct Usage:
.my-component {
  color: var(--app-color-primary);
  background: var(--app-elevation-level-1);
  border-radius: var(--app-shape-small);
}
❌ Avoid:
.my-component {
  color: #6750a4; /* Direct MD3 token */
  background: 0px 1px 3px rgba(0, 0, 0, 0.3); /* Hardcoded elevation */
}

Adding New Components

  1. Use semantic tokens exclusively for styling
  2. Follow MD3 component API patterns
  3. Include accessibility features (ARIA labels, focus management)
  4. Add Storybook stories with design system variants
  5. Update component contracts documentation

Theme Customization
