# Playful Preset

## Preset Name and Description

Playful: Fun colors, irregular spacing, lively motion, whimsical typography for joy.

## Emotional Intent / Usage Scenario

For fun apps like games or social features. Evokes joy and engagement.

## Tokens Applied

- **Colors**: Base MD3 system colors (no overrides).
- **Spacing**: Irregular (e.g., '1': '5px', '3': '13px', '5': '21px').
- **Typography**: Medium to bold weights (400-600), varied sizes (e.g., heading2: 25px).
- **Motion**: Lively easing and medium durations (e.g., short2: 110ms, medium2: 330ms).

## Mapping to MD3 Layers

- **System (sys)**: Colors unchanged.
- **Reference (ref)**: Spacing and typography derived.
- **Component (comp)**: No specific overrides.
- **Motion**: Bouncy easing (e.g., cubic-bezier(0.68, -0.55, 0.265, 1.55)).
- **Elevation**: No overrides.

## DO / DO NOT

| DO | DO NOT |
|----|--------|
| Use for fun interfaces | Apply to serious tasks |
| Test for engagement | Override with linear motion |
| Ensure whimsical balance | Hardcode irregular spacing |

## Rationale

Irregular spacing and lively motion create excitement. Whimsical typography feels playful.
