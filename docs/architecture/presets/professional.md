# Professional Preset

## Preset Name and Description

Professional: Subdued colors, balanced spacing, smooth motion, formal typography for business.

## Emotional Intent / Usage Scenario

For business apps or enterprise interfaces. Conveys reliability and formality.

## Tokens Applied

- **Colors**: Base MD3 system colors (no overrides).
- **Spacing**: Balanced (e.g., '2': '8px', '3': '12px', '4': '16px').
- **Typography**: Normal to medium weights (400-500), standard sizes.
- **Motion**: Smooth easing and standard durations (e.g., short2: 100ms, medium2: 300ms).

## Mapping to MD3 Layers

- **System (sys)**: Colors unchanged.
- **Reference (ref)**: Spacing and typography derived.
- **Component (comp)**: No specific overrides.
- **Motion**: Standard easing (e.g., cubic-bezier(0.4, 0, 0.2, 1)).
- **Elevation**: No overrides.

## DO / DO NOT

| DO | DO NOT |
|----|--------|
| Use for business interfaces | Combine with playful presets |
| Maintain formal appearance | Override with bouncy motion |
| Ensure balanced layouts | Hardcode standard values |

## Rationale

Balanced spacing and smooth motion support professional workflows. Formal typography builds trust.
