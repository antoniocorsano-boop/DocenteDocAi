# Creative Preset

## Preset Name and Description

Creative: Playful colors, varied spacing, bouncy motion, artistic typography for inspiration.

## Emotional Intent / Usage Scenario

For creative tools like design apps or brainstorming interfaces. Inspires innovation and playfulness.

## Tokens Applied

- **Colors**: Base MD3 system colors (no overrides).
- **Spacing**: Varied (e.g., '2': '10px', '4': '18px', '6': '28px').
- **Typography**: Medium weights (400-500), varied sizes (e.g., heading1: 34px).
- **Motion**: Bouncy easing and medium durations (e.g., emphasized: cubic-bezier(0.34, 1.56, 0.64, 1)).

## Mapping to MD3 Layers

- **System (sys)**: Colors unchanged.
- **Reference (ref)**: Spacing and typography derived.
- **Component (comp)**: No specific overrides.
- **Motion**: Bouncy easing.
- **Elevation**: No overrides.

## DO / DO NOT

| DO | DO NOT |
|----|--------|
| Use for creative workflows | Apply to formal interfaces |
| Test motion for nausea | Override with linear motion |
| Ensure artistic balance | Hardcode varied spacing |

## Rationale

Varied spacing and bouncy motion mimic creative exploration. Artistic typography feels expressive.
