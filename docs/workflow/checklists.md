# Checklists

## Pre-Commit Checklist

- [ ] No className in components.
- [ ] All styles use tokens.
- [ ] Tests wrap with M3ThemeProvider.
- [ ] ESLint passes.

## Migration Checklist

- [ ] Tokens separated from theme.
- [ ] Components use M3 variants.
- [ ] Emotional presets tested.

## Note

Checklists are workflow aids. Not architectural rules.

## Rationale

Checklists ensure compliance but are procedural.
